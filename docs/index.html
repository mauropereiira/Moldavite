Notes that stay yours.

Moldavite keeps every note as a plain Markdown file on your computer. Fast local search, daily notes, and the AI tools you choose, with nothing sent anywhere you didn't decide.

How Moldavite works

Files, not a database

Every note is a Markdown file in a folder you pick. Sync it with iCloud, Dropbox or git, or open it in any other editor.

Search that stays home

Full-text and semantic search both run on your computer. No note is uploaded to be indexed.

No account, no telemetry

There is nothing to sign up for. If Moldavite disappeared tomorrow, every note would still be where you left it.

Everything a notebook needs.

Daily notes, links between ideas, and a few quiet tools that stay out of the way until you want them.

Daily notes and a calendar

Today opens today's note. Weekly notes and your calendar sit right beside it.

Links between ideas

Type [[ to link one note to another. Backlinks and a graph show what connects.

Locked notes

Encrypt a single note with a password. Locked notes are never indexed or shared with AI tools.

Clip the web

Save the page you're reading as Markdown from Chrome, Edge, Brave or Firefox.

Sandboxed plugins

Add commands with plugins that get only the access you approve, one permission at a time.

Bring your Obsidian vault

Import a vault into a new Forge in one step. Your original folder is never touched.

Bring your own AI. Keep the keys.

A built-in MCP server lets Claude Code, Cursor and other MCP clients search and read your notes. Writing stays off until you turn it on, and locked notes are never shared.

claude mcp add moldavite -- moldavite --mcp

Named after a stone made by a meteorite.

About fifteen million years ago a meteorite struck what is now southern Germany. The heat threw molten rock across Bohemia, where it cooled into a green glass found almost nowhere else.

It has kept its shape ever since. Your notes should too.
