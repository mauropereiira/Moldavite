Try it here

Write a note. Keep the file.

This editor runs in your browser. Nothing is uploaded and nothing is saved anywhere. Write something, download it, and drop the file into your Forge — it opens in Moldavite because it was a Markdown file the whole time.

Downloads as impact-glass.md. Move it into Moldavite/<your Forge>/notes/ and it appears next launch.
