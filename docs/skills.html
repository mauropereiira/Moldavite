Agent Skills

Give your agent the Moldavite manual.

Five focused skills teach Claude Code, OpenCode and other compatible AI clients how Moldavite stores notes, how Forges work, and how to use the app's MCP server safely.

On this page What a skill is The five skills Install the skills Connect the MCP server Read and write tools

What a skill is

An Agent Skill is a folder with a SKILL.md file. The file gives your AI client Moldavite's product rules, safe workflows, and the exact behaviour it should expect.

Install the folders once. Compatible clients load a skill's instructions only when your request matches it, so they cost nothing until they are useful. Skills give your agent the context; the MCP server gives it the note tools. Use both for work inside a Forge.

The five skills

Each folder covers one part of Moldavite. Install the full pack so your client can pick the matching instructions.

moldavite-markdown

Create and edit Moldavite-compatible Markdown, frontmatter, wiki links and tags.

moldavite-forges

Work safely with Forge layout, paths, locked notes and direct file edits.

moldavite-mcp

Read, search, create and update notes through Moldavite's MCP server.

moldavite-daily-notes

Maintain daily notes, ISO weekly notes and Moldavite templates.

moldavite-portability

Back up, export, restore, and migrate Obsidian vaults into Moldavite.

Install the skills

Choose the method your client supports. Every method installs the same five folders.

Claude Code

Add the marketplace, then install the pack.

/plugin marketplace add mauropereiira/moldavite-skills
/plugin install moldavite@moldavite-skills

npx skills

Install straight from the repository.

npx skills add https://github.com/mauropereiira/moldavite-skills

OpenCode

Clone the repository into the global skills directory, then restart OpenCode.

mkdir -p ~/.config/opencode/skills && git clone https://github.com/mauropereiira/moldavite-skills.git ~/.config/opencode/skills/moldavite-skills

Any other client

Copy each directory under skills/ into your client's skills directory, and keep every SKILL.md beside its references/ directory. Browse the folders.

Connect the MCP server

The Moldavite app is also its MCP server. The Homebrew cask puts moldavite on your PATH, so Claude Code can start the server with one short command.

1. Install Moldavite with Homebrew

brew install --cask mauropereiira/moldavite/moldavite

2. Add the server to Claude Code

claude mcp add moldavite -- moldavite --mcp

Installed from the DMG instead? Use the app's full path:

claude mcp add moldavite -- "/Applications/Moldavite.app/Contents/MacOS/moldavite" --mcp

Pin a connection to one Forge

Add --forge when a connection should stay on a named Forge.

claude mcp add moldavite-work -- moldavite --mcp --forge "Work"

OpenCode

Save this entry in ~/.config/opencode/opencode.json, then restart OpenCode. 

{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "moldavite": {
      "type": "local",
      "command": ["moldavite", "--mcp"],
      "enabled": true
    }
  }
}

Settings, then AI and Agents in the app generates the exact line for Claude Desktop, Cursor and other stdio clients too. The guide has the details.

Read and write tools

Four read tools are on by default. Three write tools stay off until you turn them on in Settings, then AI and Agents.

Tool Does Default
search_notes Find notes by concept or keyword On
read_note Read a note's complete Markdown On
list_notes List the notes in a Forge folder On
get_backlinks Find the notes linking to a note On
create_note Create one new note Off
write_note Replace one existing note Off
append_to_daily_note Add content to today's note Off

Turning writes off blocks the next write call at once. A client's tool list catches up the next time it asks for it.

Locked notes stay locked

No tool returns a locked note's contents.
