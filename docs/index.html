# Feedback Loops

A loop is any path where an output circles back and becomes an input. Once you
start looking for them you stop seeing organisations as org charts and start
seeing them as circuits.

## The two kinds

**Reinforcing** loops amplify. Growth, compound interest, panic buying, the
rich getting richer. Left alone they run until they hit a limit.

**Balancing** loops resist. A thermostat, a hiring freeze, the way a team
quietly slows down when the backlog gets frightening.

Most surprising behaviour comes from a balancing loop you did not know was
there. See [[Thinking in Systems]] for the canonical treatment.

## Why it matters for product work

The [[Onboarding Rework]] stalled twice because we kept treating drop-off as
a line to be pushed up rather than the output of a loop.

~/Documents/Moldavite/

Everything lives in a folder called a Forge

A Forge holds daily/, weekly/, notes/, your images, and your templates. Open it in Finder. Point iCloud, Dropbox, Syncthing, or git at it. Edit a note in another app and Moldavite picks up the change.

Every write is atomic — a temp file, an fsync, then a rename, with owner-only permissions applied before the file becomes visible. A crash or a full disk cannot leave you with half a note.

Keep as many Forges as you like and switch between them. Work in one, research in another, and give each its own plugins and search index.

moldavite --mcp

Your notes become memory your tools can use

The app binary doubles as an MCP server. Point Claude Code, Claude Desktop, Cursor, or any stdio MCP client at it and they read your vault directly on your machine — no upload, no sync service, no Moldavite account in the middle.

••• Claude Code · local stdio 
$ claude mcp add moldavite -- "/Applications/Moldavite.app/Contents/MacOS/moldavite" --mcp

Settings → AI & Agents generates this line with the exact binary path on your Mac. Add --forge "Work" to point a client at a different Forge.

Not every agent speaks MCP. For the ones that just read files — Claude Code working in a directory, a script, your own tooling — one click writes an AGENTS.md describing your Forge's conventions, plus a .gitignore for the folders the app manages itself.

Tools exposed over stdio

  • list_notes Enumerate notes and locked-note placeholders, optionally scoped to a folder.
  • read_note Read one unlocked note by its Forge-relative path.
  • search_notes Ranked full-text search with snippets.
  • get_backlinks Every note that links to a given note.
  • create_note · gated Create a new note. Off until you enable writes.
  • write_note · gated Replace a note's contents. Off until you enable writes.
  • append_to_daily_note · gated Append to today's note. Off until you enable writes.

Locked notes are refused outright. Every client-supplied path is validated before it touches disk.

all-MiniLM-L6-v2

Search by meaning, entirely offline

Ask for “why did onboarding stall” and get the note that explains it, even though it never uses those words. A Related list under the editor surfaces five notes that belong with whatever you are reading.

Pick from three embedding models. The one you choose downloads once, after a prompt that names it and its size — then every query runs on your Mac, forever offline. Locked notes are never indexed.

  • Default all-MiniLM-L6-v2 — small, fast, English.
  • Higher quality BGE small English v1.5.
  • Multilingual Multilingual E5 small.
  • Requirement Apple Silicon. Intel Macs get keyword search instead.

.plugins/<id>/

Extensions that can't quietly help themselves

Every plugin runs in its own Web Worker with no DOM, no network globals, and no access to app IPC. Everything it can do crosses a message bridge the host controls, and consent is pinned to a SHA-256 hash of the manifest and code — change either byte and you are asked again.

Granted by default

  • Register commands
  • Read and replace editor selections
  • Show toasts
  • Store its own settings

Only after you agree

  • Read unlocked note metadata and Markdown
  • HTTPS to exact hosts, each revocable
  • Secrets in the macOS Keychain, namespaced per plugin
  • Host-rendered prompt forms

Never available

  • The DOM or the app window
  • fetch, XMLHttpRequest, WebSockets
  • Tauri IPC — withGlobalTauri stays off
  • Another plugin's secrets
  • Locked notes, in any form

Installing is deliberate. The community registry is contacted only when you press Browse. Downloads are constructed only under the pinned repository, and Rust verifies both SHA-256 hashes before an atomic install. Website install links use moldavite://plugin/<id>, which opens the entry and shows its permissions — enabling it is still a separate, explicit step. The first-party Publish to WordPress plugin is a worked example you can read.

AES-256-GCM

Local is the default, not a mode

There is no account system, no hosted notes service, and no telemetry to switch off. What follows is the complete list of times Moldavite touches the network — written out so you can check it against the source.

Files you own

Real Markdown with YAML frontmatter, atomic saves, and owner-only permissions. Individual notes can be encrypted with AES-256-GCM and Argon2, and stay encrypted at rest.

A local index

Your chosen embedding model downloads once from Hugging Face after you opt in. After that, indexing and querying happen on your Mac. Model files live outside the Forge.

Narrow plugin powers

A plugin can reach the network only through net.fetch, only to hosts you approved by name, with redirects checked against the same list.

Sync you control

If a note changed on disk while you had unsaved edits, the disk version is preserved as a timestamped conflict copy before yours is written. Nothing is silently overwritten.

The whole network story: a signed, notarized update check runs about fifteen seconds after launch and once a day thereafter; the plugin registry is fetched from GitHub only when you press Browse; a semantic model downloads from Hugging Face only after you opt in; and a plugin can send data only to hosts you approved. That is the list. Publishing a note to WordPress is something you do on purpose — not evidence that “nothing ever leaves”.
