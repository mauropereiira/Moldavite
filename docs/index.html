Notes that stay yours. Moldavite keeps every note as a Markdown file on your computer, with local search and a built-in bridge for the AI tools you choose.

Download Moldavite ↗ Write a note first

  • Plain Markdown

    Every note is a .md file in a folder you pick. Sync it, back it up, or open it in any other editor. Nothing is trapped in a database.

  • Search that stays home

    Full-text and semantic search both run on your machine. No note is uploaded to be indexed, and there is no account to make.

  • The AI tools you choose

    A built-in MCP server lets Claude Code and other clients read your notes, and write only when you allow it.

  • Clip a page in one click

    A browser extension saves what you are reading as Markdown, links kept and images dropped, with Moldavite open or closed. It comes from the latest release rather than a store, so Chrome needs Developer mode and the Firefox file is signed by Mozilla without being listed there.

Install

Choose how you want to install.

Use Homebrew or a signed and notarized DMG on macOS, or an x64 installer on Windows.

01

Homebrew

One command

The cask installs Moldavite and links its binary onto your PATH.

brew install --cask mauropereiira/moldavite/moldavite
View the Homebrew tap ↗
02

Disk image

Download the DMG

Open the latest release, download the macOS disk image, and move the app to Applications.

Open the latest release

Updates are verified inside the app before installation.

03

Windows

Run the EXE or MSI

Open the latest release and download the x64 setup EXE or Windows Installer package.

Open the latest release

The installer is not Authenticode-signed, so SmartScreen may warn you. Choose More info, then Run anyway if you downloaded it from the official release page.

Free and open source
